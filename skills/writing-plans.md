# Writing Plans

## Philosophy
After design approval, the work must be broken down into bite-sized tasks (2-5 minutes each). Every task must be explicit enough for a junior engineer to execute without question.

## Elements of a Task
Every task must contain:
1. Exact file paths to create or modify.
2. The complete code or logic changes required.
3. Explicit verification steps to confirm the task is done and working correctly.
4. No ambiguity.

## Principles
- **DRY** (Don't Repeat Yourself)
- **YAGNI** (You Aren't Gonna Need It)
- Focus strictly on MVP features.

## When to use
Activates with an approved design. Used primarily during the Planning phase.
